# MySkedul - Academic Operating System

![MySkedul Banner](logo.png)

## Overview
MySkedul is a high-performance academic assistant designed to help students manage their lectures, tasks, and schedules with a premium, native-like mobile experience.

## Project Evolution (Per-Day Phases)
This project is divided into four distinct phases to show the progress of development:

### 🚀 Phase 1: Foundation
*   **Goal**: Create the core scheduling logic.
*   **Features**: Basic class list, simple UI structure, and functional state management.
*   **Focus**: Stability and core utility.

### ✨ Phase 2: UI Evolution
*   **Goal**: Elevate the brand identity and user experience.
*   **Features**: Integration of **DM Sans** typography, sleek **Glassmorphism** effects, and a premium color palette.
*   **Focus**: Aesthetics and premium feel.

### 📊 Phase 3: Extended Features
*   **Goal**: Add power-user tools and academic metrics.
*   **Features**: Notification engine for lecture alerts, academic performance stats, and advanced subject management.
*   **Focus**: Functionality and productivity.

### 🌪️ Phase 4: Final Production
*   **Goal**: Liquid-smooth mobile experience and data portability.
*   **Features**: **Glide-smooth** horizontal swipe navigation, GPU-accelerated animations, and native JSON schedule sharing.
*   **Focus**: Performance and production-readiness.

## How to Run
1.  Open any `index.html` file in your preferred web browser.
2.  For the best experience, use a mobile device or Chrome DevTools in Mobile view.

## Technologies Used
*   **HTML5 & Vanilla CSS**: For structure and high-performance styling.
*   **JavaScript**: Core logic and smooth animations.
*   **Lucide Icons**: For a modern, clean interface.
*   **Capacitor**: Ready for Android/iOS deployment.
